# 点击计数（siyuan-click-counter）

**双击**块里的数字就 +1，给「喝水：1次」「1/7」这类日记/清单里的小计数块用。单击保持正常编辑，互不影响。

## 生效条件

满足其一即可：

1. **规则命中**：块首行能被「匹配规则」里的正则命中。默认规则覆盖三类写法：
   - 名称 + 数字（+单位）：`喝水：1次`、`喝水: 1 次`、`喝咖啡：2杯`、`俯卧撑：30个`
   - 名称 × 数字：`喝水 ×3`、`喝水 ✕3`
   - **当前/目标**：`1/7`、`喝水：1/7`、`学习 3/10` —— 只累加斜杠前的数字，分母不动，
     且**到分母封顶**：7/7 之后双击不再变化，只提示 `喝水：7/7（已达目标）`
2. **块属性**：块上写 `custom-click-counter`（属性值语义见下）

## 操作

| 操作 | 结果 |
| --- | --- |
| **双击**该块 | 数字 ± 步长，块闪一下并提示新值（顺带抑制"双击选中单词"） |
| 单击该块 | 正常编辑 / 放光标，不计数 |
| `Alt`（或 Ctrl/Shift）+ 双击 | 不计数（想在计数块里双击选词时用） |
| 块图标菜单 | 「计数 +1 / 计数 -1」 |
| 命令面板 | 打开设置、光标所在块 ±1、诊断当前块为何不计数、检查界面上的残留块 |

连续快速双击会排队累加，不会漏。**边界**：带分母的写法到 `M` 封顶；其它写法只保证不低于 0，
可以一直往上加。

## 块属性 `custom-click-counter`

| 值 | 含义 |
| --- | --- |
| `off` / `no` / `false` / `0` | 该块不计数 |
| `+1` / `-1` / `2` | 该块单独指定步长（负数表示双击就是减少） |
| 其他值（如 `on`） | 强制启用；规则没命中时，退回改「行尾最后一个数字」，如 `俯卧撑 30` |

## 不参与计数的情况

- 代码块、公式块、HTML 块、图片、块引用、属性视图、块标菜单等区域；
- 只读预览、对话框里的静态渲染；
- **只存在于界面、内核里没有的前端临时块**——典型是智能体对话框的消息气泡与输入框。
  计数前会先查库确认块存在，缺失就静默跳过，**不发出任何会失败的请求**，因此不会弹
  `block not found` 之类的报错。

## 设置

设置 → 集市 → 已下载 → 点击计数（齿轮），或命令面板搜索「点击计数」。

- 启用开关、每次增量
- 匹配规则：一行一条正则，**需含 3 个捕获组**（名称 / 数字 / 单位），单位可空；支持 `/正则/标志` 写法；`#` 开头为注释行
- 闪一下、提示新值、调试日志（输出到控制台）

## 实现要点

1. 捕获阶段监听 `mousedown`，**只在 `event.detail === 2`（双击的第二次按下）时动作**：先按规则筛选，
   确认命中后 `preventDefault()` 抑制"双击选中单词"，再走 `SQL 存在性校验 → getBlockKramdown → updateBlock`；
2. 命中的是「捕获组 2」的数字，只替换这一处字符，其余原样保留 —— 所以 `1/7` 只会变成 `2/7`；
3. 若「单位」里能认出分母（如 `/7`），新值按 `min(分母, 原值+步长)` 封顶；已到边界就只提示、不回写；
4. 回写用 markdown，inline 格式（加粗、引用等）保留；`id` / `updated` 不写回，其余自定义属性原样带上；
5. 只处理单行的块；多行块（带子块）直接跳过，避免回写丢内容；
6. 只认 `.protyle` 内、非只读区域的 `段落 / 标题 / 引述 / 表格单元格`；
7. 同一块上的连点排队累加，回写前留 100ms 让可能的编辑事务落库。

## 版本

- v1.0.x 期间为定位「点击后弹 block not found」，加过落盘日志、失败请求抓取、ws 埋点与启动扫描；
  根因是智能体对话框把消息气泡/输入框渲染成了从不入库的临时块（v1.0.8 用「计数前先查库」根治）。
- v1.1.0：移除全部排障脚手架。
- v1.2.0：触发方式由单击改为双击。
- v1.2.1：默认规则新增「当前/目标」写法（`1/7`），会平滑升级没改过规则的老配置。
- v1.2.2：`N/M` 到分母封顶，到顶后只提示不再回写。
