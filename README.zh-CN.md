# 点击计数（siyuan-click-counter）

**双击块里的数字就自动累加** —— 给日记、清单里「喝水：1次」「1/7」这类小计数块用；单击仍然是正常编辑，互不影响。

兼容思源笔记 v3.0.0+ · 包名 `siyuan-click-counter` · [仓库](https://github.com/Fly1018/siyuan-click-counter)

## 核心功能

- **双击计数**：双击命中的块，只替换那一处数字，行内格式（加粗、引用等）与其它自定义属性原样保留
- **到目标封顶**：`1/7` 这类「当前/目标」写法，双击累加斜杠前的数字，到 `7/7` 后只提示、不再改动
- **单击不受影响**：单击仍是放光标和编辑；按住 `Alt`（或 `Ctrl`/`Shift`）双击也不计数，方便在计数块里选中单词
- **只改数据，不改页面文字**：计数前先查库确认块真实存在，再取块内容、按 markdown 回写，不是直接改页面上的字符
- **连点不丢**：同一个块上的连续双击会排队累加
- **三个额外入口**：块图标菜单、命令面板、块属性 `custom-click-counter`（可给单块指定步长）

## 适用场景

- 日记 / 清单里的习惯打卡：`喝水：1次`、`喝咖啡：2杯`、`俯卧撑：30个`
- 有明确目标的进度计数：`1/7`（一周七次）、`学习 3/10`（十页书）
- 表格单元格里的计数（表格单元格同样支持）
- 临时给某一块单独设步长，比如每天记录一次、希望一次 +2

## 安装与启用

**方式一：集市安装（推荐）**

1. 思源 → <kbd>设置</kbd> → <kbd>集市</kbd> → <kbd>插件</kbd>，搜索「点击计数」
2. 点安装
3. 到 <kbd>设置</kbd> → <kbd>集市</kbd> → <kbd>已下载</kbd>，把「点击计数」的开关打开

**方式二：手动安装**

1. 从 [最新 Release](https://github.com/Fly1018/siyuan-click-counter/releases/latest) 下载 `package.zip`
2. <kbd>设置</kbd> → <kbd>集市</kbd> → <kbd>已下载</kbd> → 从 `package.zip` 安装
3. 同样在「已下载」里启用

启用后**无需任何配置**即可使用：默认规则已覆盖三种常见写法，直接双击就能计数。

| 项目 | 要求 |
| --- | --- |

## 快速上手

1. 新建一篇文档，输入一行：

   ```
   喝水：1次
   ```

2. **双击这一行** → 变成 `喝水：2次`，同时该块闪一下（蓝色）、右下角提示新值

3. 再输入一行 `1/7`，双击 → `2/7`。连着双击到 `7/7` 后再双击，只会提示 `7/7（已达目标）`，不再变化

4. 单击同一行 → 只是放光标，可以正常编辑文字，不会计数

默认规则覆盖的三类写法：

| 写法 | 示例 | 双击后 |
| --- | --- | --- |
| 名称 + 数字（+ 单位） | `喝水：1次`、`喝水: 1 次`、`喝咖啡：2杯`、`俯卧撑：30个` | `喝水：2次`、`喝咖啡：3杯`、`俯卧撑：31个` |
| 名称 × 数字 | `喝水 ×3`、`喝水 ✕3` | `喝水 ×4` |
| 当前 / 目标 | `1/7`、`喝水：1/7`、`学习 3/10` | `2/7`、`喝水：2/7`、`学习 4/10`，只动斜杠前的数字，到分母封顶 |

## 配置项

<kbd>设置</kbd> → <kbd>集市</kbd> → <kbd>已下载</kbd> → 点击计数（齿轮图标）；
也可以在命令面板搜索「点击计数：打开设置」。

| 设置项 | 含义 | 默认值 |
| --- | --- | --- |
| **启用双击计数** | 总开关。关闭后双击不再计数 | **开** |
| **每次增量** | 双击一次数字增加多少。可填**负数**（双击就是减少），也支持小数（如 `0.5`）；填 `0` 或非数字会退回 `1` | **1** |
| **匹配规则** | 一行一条正则，需含 **3 个捕获组**：名称 / 数字 / 单位（单位可空） | 见下方三条默认规则 |
| **计数动画** | 命中时该块闪一下（增加为蓝色，减少为红色） | **开** |
| **计数提示** | 命中时弹出新数值 | **开** |
| **调试日志** | 在控制台输出匹配与回写细节，排障用 | **关** |

### 默认匹配规则

```
^(\S.{0,38}?)\s*[:：]\s*(\d+)\s*(次|杯|个|遍|组|下|页|口|瓶|颗|片|场|分钟|小时|公里|km)?$
^(.{1,40}?)\s*[×✕]\s*(\d+)\s*$
^(?:(\S.{0,38}?)\s*[:：]?\s*|[ \t]*)(\d{1,3})(\s*[\/／]\s*\d+.*)$
```

分别覆盖 `名称：数字[单位]`、`名称 ×数字`、`当前/目标`。

规则写法要点：

- 一行一条；空行忽略；`#` 开头是注释行
- 支持 `/正则/标志` 写法，也可以直接写裸正则
- **裸正则默认加 `i` 标志**（不区分大小写）；`/正则/标志` 写法里的 `g`、`y` 会被自动去掉
- 正则语法错误的那一行会被**静默忽略**，不影响其它规则
- 捕获组 2 必须是**纯数字**（`\d+`），否则该条不算命中
- 改动后立即生效，不需要重载插件

## 进阶用法

### 块属性 `custom-click-counter`

写在块上，用来单独控制这一块：

| 值 | 含义 |
| --- | --- |
| `off` / `no` / `false` / `0` | 该块不计数（不区分大小写） |
| 整数，如 `+1` / `-1` / `2` | 该块单独指定步长；只认整数、不能为 0，负数表示双击即减少。**优先于全局「每次增量」** |
| 其他值，如 `on` | 强制启用：即使规则没命中，也退回改「行尾最后一个数字」，如 `俯卧撑 30` |

### 块图标菜单

单击块标（块左侧的图标）→ 菜单里有 **「计数 +1」/「计数 -1」**。多选多个块时对每个块都生效。这条路径与双击互不影响。

### 命令面板

默认**都没有快捷键**，可在 <kbd>设置</kbd> → <kbd>快捷键</kbd> 里自行绑定：

| 命令 | 作用 |
| --- | --- |
| 点击计数：打开设置 | 打开插件设置面板 |
| 点击计数：光标所在块 +1 | 按「每次增量」（或该块自己的属性步长）给光标所在块加一次，不改动光标位置 |
| 点击计数：光标所在块 -1 | 同上，减一次 |
| 点击计数：诊断当前块为何不计数 | 输出该块的完整判断依据（见下） |
| 点击计数：检查界面上的残留块（诊断） | 扫描界面上「只有界面、内核里没有」的块 |

**诊断命令**会用一个对话框列出：所在位置、块 ID、块类型、块文字、内核中是否存在、`custom-click-counter` 属性值、首行内容、启用状态、当前步长、规则条数，以及**匹配结果**（命中时会显示解析出的名称 / 数字 / 单位，以及上限）。计数行为不符合预期时，先跑这个命令。

### 自定义规则示例

```
# 每行一个，注释这样写
^完成\s*(\d+)\s*(次)$
^reading\s+(\d+)\s*(pages)$
```

## 已知边界

- **只处理单行块**。带子块的多行块会直接跳过，避免回写时丢内容
- 只有这些块类型参与计数：**段落、标题、引述、表格单元格**（容器块交给它们内部的段落处理）
- 只认 `.protyle` 编辑器里的块；只读预览、对话框里的静态渲染不处理
- 代码块、公式块、HTML 块、图片、块引用、属性视图、块标菜单等区域不参与计数
- 数字只保证**不低于 0**；只有带分母的写法（如 `/7`）才会封顶
- 块的 ID 形态必须是 `14 位时间戳-7 位随机串`，不符合的会跳过（正常文档里的块都符合）

## 常见问题

**双击了但没反应**

1. 先确认插件已启用：<kbd>设置</kbd> → <kbd>集市</kbd> → <kbd>已下载</kbd> → 点击计数，开关是否打开
2. 用命令面板跑「**点击计数：诊断当前块为何不计数**」，看最后一行的「匹配结果」：
   - 显示「未命中（不计数）」→ 说明规则没覆盖这种写法，去设置里加一条规则
   - 显示「内核中存在：否」→ 这是前端临时块，见下面一条
3. 检查该块是否有 `custom-click-counter`，且值写成了 `off` / `no` / `false` / `0`
4. 确认块类型是段落 / 标题 / 引述 / 表格单元格，并且不是带子块的多行块

**到目标值之后双击没反应**

这是设计如此：`N/M` 到达分母 `M` 就封顶，只会提示「（已达目标）」，不回写。想继续加就把分母改大。

**提示「这个块只存在于界面、内核里没有」**

这类块是前端临时渲染出来的（最常见的是智能体对话框里的消息气泡与输入框），不会入库。插件计数前会先查库确认，遇到这类块**直接静默跳过**，不会发出会失败的请求，也不会弹 `block not found` 之类的报错。可以用「检查界面上的残留块」命令查看全部情况。

**双击后变成了选中单词**

命中计数时插件会主动抑制「双击选中单词」。如果你想选中单词，按住 `Alt`（或 `Ctrl`/`Shift`）再双击即可。

**行内格式会丢吗？**

不会。只替换捕获到的那一处数字，加粗、引用等格式以及其它自定义属性都原样保留；`id` 和 `updated` 由内核维护，不回写。误操作可以用思源自带的撤销（`Ctrl+Z`）。

**快速连点会漏计数吗？**

不会。同一个块上的连续双击会排队累加，等前一次回写完成再继续。

## 开发与发版

**仓库根目录就是插件本体**：思源直接加载 `index.js`（CommonJS，`require("siyuan")`），不需要编译或构建，改完保存即可生效。完整的版本记录见 `CHANGELOG.md`。

```bash
python3 scripts/pack.py          # 校验并打出 package.zip
python3 scripts/pack.py --check  # 只校验，不生成
```

发版步骤：

1. 改 `plugin.json` 里的 `version`，并在 `CHANGELOG.md` 补一条；
2. 提交，打一个与版本号一致的 tag 并推送：

   ```bash
   git tag v1.2.3 && git push origin v1.2.3
   ```

3. GitHub Actions 会校验 tag 与版本号一致 → 打包 `package.zip` → 发布 Release。

集市索引会在 1–3 小时内自动拉到新版本，**不需要再提 PR**。
